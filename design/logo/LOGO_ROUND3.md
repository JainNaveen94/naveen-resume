# Logo round 3 — Architect / Principal Engineer (no photo, no NJ monogram)

## Design rules

- **No photograph** in mark or favicon.
- **No** crowded initials in a gradient app tile.
- **Abstract** symbols for **system architecture**, **structure**, **leadership of design**.
- **Consulting tone:** slate + single accent stroke; gradient only as subtle accent if needed.
- **Favicon-first:** must read at 16×16.

## Concepts

| ID | Name | Meaning |
|----|------|---------|
| **G** | **Blueprint** | Registration corners + **hub node** + spokes → system blueprint |
| **H** | **System graph** | Three nodes, three links → services / principal orchestration |
| **I** | **Load-bearing arch** | Arch + deck → architect as structural lead |
| **J** | **Isometric module** | One clean **3D block** → platform / component boundary |

## Recommendation for *Principal / Full-Stack Architect*

**H (System graph)** or **G (Blueprint)** — clearest at small size, reads “software architecture” without civil-engineering cliché.

After you pick **G / H / I / J**, we refine one set in `design/logo/final/` then implement on the site.
